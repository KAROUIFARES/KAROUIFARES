## Projets à découvrir

### 🩺 SurgiGuard — Surveillance post-opératoire connectée

Solution complète de suivi à domicile : capteurs ESP32, MQTT, API ASP.NET Core, MongoDB, application mobile et assistant IA. Le système centralise les mesures, détecte les alertes et aide le patient ainsi que ses proches à suivre son rétablissement.

→ [Voir le projet](https://github.com/KAROUIFARES/SurgiGuard)

### 🌤️ AeroSense — Station météo intelligente

Station IoT de suivi météorologique et de qualité de l’air, intégrant ESP32, MQTT sécurisé, conception électronique et dashboard Android natif avec Jetpack Compose.

→ [Voir le projet](https://github.com/KAROUIFARES/AEROSENSE)
