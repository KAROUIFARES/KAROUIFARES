## Projets à découvrir

### 🩺 SurgiGuard — IoT Edge, Pipeline Data ETL & IA Multi-Agents
Solution de télésurveillance médicale à domicile : un ESP32 collecte les constantes vitales (pouls, SpO₂, mouvement)[cite: 1], transmises via MQTT vers un pipeline d'ingestion ETL temps réel[cite: 1, 17]. Un système multi-agents intelligent analyse les métriques stockées et déclenche des alertes automatisées[cite: 1, 17]. *(2ᵉ prix Hackathon HackCure 2026)*[cite: 1, 16]
→ [Voir le projet](https://github.com/KAROUIFARES/SurgiGuard)

### 🏭 NeoGest — Industrie 4.0, IoT & Architecture Data
Système centralisé de gestion industrielle, d'entrepôt et de suivi RH[cite: 1]. NeoGest combine des terminaux IoT ESP32 (RFID, capteurs), la localisation par guidage lumineux, une architecture microservices **.NET / RabbitMQ** et la centralisation analytique des données (SQL/NoSQL)[cite: 1, 15, 17].
→ [Voir le projet](https://github.com/KAROUIFARES/NeoGest)

### 🌤️ AeroSense — Station météo IoT & Ingestion de données
Station environnementale intelligente : acquisition par ESP32, transmission MQTT/TLS sécurisée, stockage dans des bases de données historiques et restitution sur dashboard Android natif (Jetpack Compose)[cite: 1].
→ [Voir le projet](https://github.com/KAROUIFARES/AEROSENSE)

### 🧪 Big Data, IA & Multi-Agents Projects
Projets axés sur l'ingénierie des données et l'IA de pointe : pipelines de données distribués, fine-tuning et distillation de modèles de langage (LLM) avec méthodes d'optimisation (GRPO, LoRA)[cite: 1, 17], et conception de systèmes d'agents autonomes collaboratifs (LangChain / LangGraph)[cite: 1, 17].
→ [Protein-LLM-Distillation-GRPO](https://github.com/KAROUIFARES/Protein-LLM-Distillation-GRPO) · [AgenticHire](https://github.com/KAROUIFARES/AgenticHire)
